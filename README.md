# Gerenciador de tarefas e tempo de foco

Projeto criado para a Escola de Inverno em Desenvolvimento Web para Meninas (Grace ICMC USP).

## Funcionalidades

- Criação e exclusão de tarefas na aba principal do App ("home")
- Cronomêtro de foco na aba "foco" da aplicação

## Instalação e uso local

1. Clone este repositório
2. Instale as dependências com `pip install -r requirements.txt`
3. Crie um arquivo `firebase.json` na pasta raiz contendo as credenciais do seu projeto na FireStore do Google
4. Rode a aplicação com `streamlit run app.py`
